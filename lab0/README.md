# Lab 0 — OOP (C++)

## Опис
Стартовий проєкт для лабораторної роботи №0 з курсу "Об'єктно-орієнтоване програмування".

## Вимоги
- Компілятор C++17 (g++ / MSVC / clang)
- CMake >= 3.10 (опціонально)

## Збірка та запуск

### Варіант 1: через g++ напряму
```bash
g++ -std=c++17 -o lab0 main.cpp
./lab0
```

### Варіант 2: через CMake
```bash
mkdir build
cd build
cmake ..
cmake --build .
./lab0
```
